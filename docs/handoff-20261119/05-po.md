## 6. 关键实现约定（接手人必读）

- **node 直接跑 .ts 不支持构造器参数属性**：类字段必须显式声明 + 构造器 `this.x = x`。
- **zod `.default()` 字段在 `z.infer` 输出类型里是必填的**：RPC 调用侧要显式传（如 `refresh:false`）。
- **fflate**：`gzipSync` 返回 `Uint8Array`，需 `Buffer.from(...).toString('base64')`。
- **PM 文档测试**：`richSchema.nodeFromJSON(new RichDocument(html).document)`（`RichDocument.document` 是 JSON 不是 PM Node）。
- **`fs.mkdirSync(recursive)` 已存在时返回 undefined**，不能与 `writeFileSync` 用 `&&` 串联（测试 fixture 踩过）。
- **面板 key 不能用 `lintTick`**：否则每次编辑重挂载、面板自动关闭（已修，key 只用 `draft.id`）。
- **变更对比硬性规则**不适用于本处的术语替换预览：C3 规格原写「左右并排 diff」，我实作为**面板内行内二次确认**（显示 from→to 与「全文」范围），理由是一条术语替换做全篇并排 diff 不成比例。**此为偏离规格的实现决策，需总负责人确认或改回。**
- 规格文档中 **C4「工作台头部徽章」实际落在状态栏**（`rich-statusbar`），非头部。
