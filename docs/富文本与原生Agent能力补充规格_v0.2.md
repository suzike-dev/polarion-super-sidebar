# 富文本与原生 Agent 能力补充规格 v0.2

2026-11-03，依据用户本轮明确补充。此文件补充已批准 v0.1，不缩减原有范围。实现进度与能力要求分开记录；没有运行证据的功能不得标记完成。

## 1. 已确认边界

- 浮窗是 Polarion 原装富文本编辑器的完整替代。不能把“可以回原生编辑器完成”作为已覆盖。
- 正文体验对标飞书文档。用户选择 C：第一版增强文档表格；数据库字段类型、公式、多视图后续实现。这不缩减正文、图片、附件、粘贴和原生表格功能。
- 文本、表格、图片、色块、高亮、编号等均可在浮窗内创建、编辑、复制、粘贴。支持文件选择、拖放和剪贴板图片。
- AI 对话框支持文本粘贴、文档/图片选择与拖入、直接粘贴截图；附件作为上下文展示并随发送冻结。
- Claude Code 完整本地能力保留，包括真实斜杠命令、用户配置的 Skills/MCP、工具与权限交互。加载配置不等于所有服务可用；显示实际状态。
- 可视化、交互、配色和正文排版都要达到适合工程阅读的质量，有清晰的层级关系。

## 2. 富文本能力与验收

| 类别 | 第一版必须覆盖 | 验收方式 |
|---|---|---|
| 文字 | 字体、字号、粗体、斜体、下划线、删除线、上/下标、颜色、高亮、清除格式、符号 | 编辑与重新打开一致，原生回读可见 |
| 段落 | 标题层级、对齐、缩进、行距、段距、引用、色块、分隔线 | 层级清楚，键盘与工具栏结果一致 |
| 序列 | 有序/无序列表、嵌套、起始编号、缩进/反缩进、退出列表 | 从粘贴与手工创建进入同一结构 |
| 表格结构 | 插入、嵌套、增删行列、行列移动、剪切/复制/粘贴行、多格选择、合并/拆分、表头/首列 | 合并及嵌套样本无内容丢失；撤销重做有效 |
| 表格属性 | 总宽与单位、列宽、行高、水平/垂直对齐、边框样式/宽度/颜色、单元格间距/内边距、背景色、表头、首列加粗、分页属性 | 属性有明确入口，保存与回读保留 |
| 粘贴 | 纯文本、带格式文本、Word/网页内容、Excel 表格、TSV 矩阵、图片/截图 | 区分正常/纯文本粘贴；粘贴到现有单元格不会意外嵌套；不执行粘贴脚本 |
| 图片 | 选择/拖入/粘贴、预览、缩放、尺寸、比例、对齐、说明、替换/删除 | 图片字节/附件归属/正文引用三者回读一致，刷新后仍能显示 |
| 附件与文档 | 选择本地文件、已有工作项/文档附件、插入链接或预览、查看归属与基本属性 | 浮窗内完成，禁止只留原生跳转入口作为完成 |
| 链接与工程对象 | 网页链接、工作项引用、附件链接、原生受支持宏与特殊内容 | 引用与身份保留；暂未实现专用编辑的对象明确属于未完成项 |
| 审阅与恢复 | 同一草稿、撤销重做、查找替换、可读差异、草稿恢复、版本冲突 | AI/手工冲突不覆盖，异常保存需回读 |
| 文档级操作 | 章节、工作项与正文块、编号、拆分/合并/重排等，沿用 v0.1 FR-11—FR-16 | 与 Polarion 实际 LiveDoc 结构一致 |

原生页面补查已观察到：字体、清除格式、列表与缩进、对齐、评注、图像/附件预览；表格菜单提供插入、剪切/复制/粘贴行、移动、删除、对齐、合并、表格属性。实际“插入表格”弹窗包含行列、总宽、水平/垂直对齐、加粗列、列头、边框、单元格间距、没有分页符。图片插入弹窗区分工作项附件与文档附件。补查记录位于 ego 开发空间 2，round-69 至 round-78；未提交原生编辑。

## 3. 阅读与交互质量

1. 统一标题、正文、表格、备注、引用和提示色块的层级；使用有限且语义明确的颜色，不靠装饰区分内容。
2. 页面留白与阅读行宽适配真实软件需求；复杂表格可横向滚动、专注编辑，不挤压成不可读窄列。
3. 文字工具、表格工具、图片属性与插入入口具有稳定分组。选中对象后显示相关属性，不能把常用操作藏在无提示的菜单里。
4. 支持浮窗调整大小、专注编辑、返回原上下文，保持大纲与助手位置关系；原生菜单和模态窗不能被扩展挡住。
5. 使用真实正文、大表格、嵌套表格、图片、长段落、列表与色块样本验收。空白页面、简单样例截图不能代表完成。
6. 分别验证编辑视图、阅读预览、Polarion 原生回读；不得通过修改现有工程参数来“美化”。

## 4. AI 附件上下文

上传入口、拖放与粘贴统一进入本地附件仓库。卡片显示名称、类型、大小、读取/解析状态，可预览及移除。文本粘贴保留直接输入；长材料可转为上下文文件。发送时固定附件 ID、内容校验值和目标，不随之后的增删变化。

文档至少覆盖常用 PDF、Word、Excel、PowerPoint、文本和图片。区分“文件已加入”“内容已解析或被原生工具读取”“模型已实际采用”；解析失败不可显示已读取。图片应交给支持图像的原生模型/工具；实际提供方拒绝图像时显示具体失败，不能假装识图。原文件保留，不把内容发给额外未授权服务。

## 5. Claude Code 原生能力

- 从本机运行时获取命令、Skills、Agent、模型与 MCP 清单，支持搜索和斜杠补全，不硬编码一小组命令冒充完整能力。
- 斜杠输入必须按原生命令发送，不能加普通聊天前缀导致命令失效；本机配置、项目配置及已有原生会话保持连续。
- 命令返回、上下文/用量信息、工具进度、原生提问、权限确认、MCP elicitation 都需要侧栏交互承接。
- MCP 显示已连接、连接中、失败、需要登录、停用，以及真实工具列表；提供原生重载/重连入口。不得改写全局配置来让侧栏看起来正常。
- 区分 SDK 已支持的命令与当前尚未接入的终端交互；未接入项属于产品缺口，不静默丢弃或转为模型猜测。
- Polarion 正式提交继续经明确保存通道；原生能力保留不绕过已确认的草稿/保存边界。
