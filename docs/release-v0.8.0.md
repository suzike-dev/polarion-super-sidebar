## v0.8.0 — 分享到飞书：项目共享的群机器人卡片

### 变更管理 · 分享到飞书
- **交互卡片直发**：绿色题头（`需求变更速览 · 项目号`）、文档名、变更区间与规模、AI 结构化总结（超长截断）、人工备注，底部一个 **「打开逐项对照页」** 主按钮。
- **推送群按项目共享**：变更工作台右上角纸飞机入口，一个项目可加多个群（群备注名 + webhook + 可选签名密钥），支持「发送测试卡片」。配置以 `PSB-FEISHU` 工作项 + 附件写入 Polarion，一人配置、全项目成员共用；本机仅作离线缓存，并发改动会提示重新加载。
- **谁都打得开**：分享时把该记录的整页对照渲染成单文件 HTML（`sidebar-change-<recordId>.html`）写进记录工作项附件，卡片按钮直接指向 Polarion 附件地址，不依赖分享者电脑在线；上传失败自动退回记录工作项链接。
- **签名校验**：机器人开启「签名校验」时按 `timestamp + HMAC-SHA256` 计算 `sign`；webhook 与密钥只存 Polarion 项目附件，不进代码、不回显日志。
- **失败不阻断**：逐群反馈成功/失败原因；未配置群或全部失败时回退到「发布链接 + 复制飞书文案」。

### 其它
- 分享页补充 Polarion 深链（记录工作项、逐条变更跳转）与「所属功能单元」标注。
- Host 健壮性：Polarion worker 调用超时后自动重启该 worker，避免僵死进程让后续请求静默挂起。

### 验收
- 真实工程：`45_SPE25_BQ1_TM_002`（1 项）与 `55_SPE26_Y3_TM_004`（44 项）分别实测发卡成功，大记录 8.4 秒（含对照页上传）。
- 性能：health 8 ms、记录读取 111–267 ms、工作区读取 104 ms、群配置读取 200 ms、分享链 2.3 s（1 项）/ 8.4 s（44 项）。
- 334 项单元测试通过，Host 与扩展类型检查通过。
- 界面走查：文档页侧栏 → 变更管理（项目共享）→ 飞书推送群弹窗（显示项目共享群）→ 分享到飞书（提示已发送）。
