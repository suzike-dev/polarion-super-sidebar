## 边界与说明

- 原生对话框依赖与浏览器相同的桌面会话；在无桌面会话（服务/计划任务）中会超时返回，此时可用设置里的“手动输入路径”兜底。
- 引导打断依赖本地 Claude Code 的 `interrupt()`；旧版 CLI 拒绝时会记录 `steer-failed` 并在对话中提示，新输入按排队继续，不会假装已打断。
- 通用指令“必须读取”属于提示词约束而非硬拦截；索引每轮下发以保证可发现性，模型仍需自行判断相关性。
- 验收使用隔离项目 test01；未对正式需求执行写入。
