# 变体管理（2026-11-05）

## 目标

一个功能工作项可能因客户、项目、车型或配置不同而存在多个变体。主工作项保持文档槽位稳定，变体作为独立的 Polarion 工作项管理与编辑；需要时把某个变体的正文接入主工作项。

## 数据模型

| 数据 | 存储位置 |
| --- | --- |
| 主工作项（默认变体） | 当前 Polarion 文档中的原工作项，ID/位置/评论/审批不变 |
| 变体工作项 | Polarion 项目级独立工作项，不带 `documentLocation`，不进入主文档正文 |
| 归属关系 | 变体 → 主工作项的 Polarion 链接，角色可配置（默认优先 `parent`，其次 `relates_to`） |
| 变体名称 | 写入变体工作项标题：`{主标题} · 变体：{名称}`，用于跨机器发现 |
| 详细配置 | 变体工作项的 `sidebar-variant.json` 附件：客户、项目、车型、配置、备注 |
| 当前接入状态 | 主工作项的 `sidebar-variant-active.json` 附件：当前变体工作项 ID + 主正文哈希 |
| 未保存编辑 | 本地草稿；保存后才写入 Polarion |
| 接入撤销快照 | 本地保留最近 20 次；Polarion 工作项历史仍是最终追溯来源 |

主工作项在面板中默认显示为「默认」变体。首次接入其他变体前，Host 先把主工作项当前正文捕获为一个独立的「默认」变体工作项，避免覆盖后丢失原始内容。

## 流程

### 新建变体

1. 面板填写变体名称；可选从主工作项复制正文。
2. Host 读取主工作项的类型，创建同类型独立工作项。
3. 建立变体 → 主工作项的链接并校验。
4. 复制正文时把 `workitemimg:` 图片重新绑定到本地资产，再通过现有草稿保存链路写入变体工作项。
5. 打开变体草稿，复用悬浮编辑器。

### 编辑变体

- `drafts.open` 按 `workItemId` 找到变体记录，读写请求携带变体作用域。
- 保存只调用变体的 `drafts.save`；跳过原生页面检查和 `native-workitem-refresh`，主工作项不受影响。
- 保存沿用现有预检、乐观并发、附件上传和回读校验。

### 接入主工作项

1. 差异预览，提示未保存草稿、空正文、画板等风险。
2. 校验主工作项未被其他人修改（`updated` + 正文哈希）。
3. 首次接入时捕获「默认」变体（正文 + 详细配置附件）。
4. 把变体正文中的 `workitemimg:` 重新绑定到主工作项，再通过现有 `Drafts.save` 链路覆盖主工作项正文。
5. 回读校验后刷新原生页面；保留接入前正文快照，支持撤销。

### 当前接入状态

优先读取主工作项的 `sidebar-variant-active.json` 附件；附件里的正文哈希与主工作项当前正文一致才生效，避免直接编辑主工作项后误报。

- 命中某个独立变体 → 该变体显示「当前接入」。
- 标记为默认（空变体 ID）且默认变体尚未捕获 → 主工作项默认行显示「当前接入」。
- 附件不可读/哈希不匹配时，依次回退到本机接入记录、最后一次接入快照、正文哈希。
- 已捕获默认变体但主工作项正文与所有变体都不一致且没有有效标记 → 提示主工作项被直接编辑，可新建变体保存当前内容。

### 跨机器发现

面板打开时读取主工作项的反向链接，按配置的链接角色筛选，再读取变体标题、正文和 `sidebar-variant.json` 重建列表；当前接入状态从主工作项的 `sidebar-variant-active.json` 读取，本地已有变体的详细配置也会在同步时重新读取。本地 SQLite 只缓存 UI 元数据和未保存草稿。

## 安全边界

Worker 对普通工作项仍要求 `item.module_uri === document.uri`。变体工作项允许不在文档内，但必须同时满足：

1. 主工作项属于当前文档；
2. 变体工作项与主工作项存在指定角色的链接；
3. 链接通过 `getBackLinkedWorkItems` 回读确认。

否则返回 `WORK_ITEM_DOCUMENT_MISMATCH` 或 `VARIANT_LINK_REQUIRED`。UI 只能通过 `variantId` 操作已登记的变体，不能直接指定任意工作项 ID。

## 限制

- 画板通过快照复制：复制时保留逻辑 objectId，生成新 snapshotId、源文件/预览/清单并绑定目标工作项；源文件或清单校验失败时阻止接入，不会写出坏画板。每个变体会各持有一份画板附件，存储体积会随变体数量增加。
- 变体工作项创建依赖项目权限、工作项类型和必填字段；失败时返回 `WORK_ITEM_CREATE_FAILED`，不会静默创建。
- 「解除」只删除本地归属与 Polarion 链接，工作项本身保留；未保存的变体草稿会一并删除。
- 撤销快照是本机安全网；跨机器撤销依赖 Polarion 工作项历史。
