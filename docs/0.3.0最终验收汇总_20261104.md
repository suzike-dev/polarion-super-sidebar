## 仍需继续开发或补验

本版不承诺任意旧 HTML、特殊宏、Office 复杂粘贴及自定义段间距的像素一致性。Codex 适配、MCP URL 登录交互、完整电子表格工作簿、多用户协作、整份 LiveDoc 编排与全部工程流程仍未完成。

免刷新保存仅支持已验收的 Polarion 21R2 构建，其他构建在远程保存前停止。SOAP 原子 CAS、第二台实体电脑/新 Windows 账号认证、完整三浏览器矩阵、30 分钟大文档和复杂画板压力目标尚未验收；当前脚本安装不等于图形安装器和自动升级产品。以上边界继续保留在 README 和版本说明中。
