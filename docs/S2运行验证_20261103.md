## 保存和故障边界

写入能力在开发代码中限定到上述隔离文档；公司正式需求没有用作写入测试。认证只进入读取 DPAPI 凭据的独立子进程，不进入浏览器或 Agent 环境。原生未保存状态结合输入事件、内容指纹及保存按钮状态；观察到的悬停装饰被单独排除，正文和格式变化继续阻止盲目保存。

Host 对同一草稿串行保存，先核对更新时间及完整正文，正式调用前持久记录未知结果，完成后独立回读。收到超时或不一致时需要重新核对服务端，不直接重试。服务端未验证原子 CAS，因此不能承诺消除最后一次预读后的所有外部并发竞态。

显示层使用隔离 iframe 和受限展示 HTML；保存使用原始片段及定位补丁，不能把展示时的处理结果回写为正式内容。图片引用无法预览时必须保留原引用并显示缺口，不当作图片已读取或已修复。
