## 可用于 README 的首次安装命令

前提：Windows x64、Git、现有 Node.js 20.11+（20.x）或 22+ 与 npm，仅用于引导；Windows PowerShell、.NET Framework 4 C# 编译器；Claude Code 已安装并认证。无需全局 Node 24；下载后通过项目私有 Node 24.22.2 执行 npm、检查与 Host，满足 `package.json` 的应用运行范围。引导脚本依赖的 `import.meta.dirname` 来源见 [Node 官方文档](https://nodejs.org/api/esm.html#importmetadirname)；本次实际引导版本为 25.2.1，没有把较低版本推导当作实机测试。

仓库访问、网络访问以及 Polarion 账号由用户准备。请选择自己有写权限的固定本地目录；UNC 网络目录、超长路径和只读目录未验收。当前产品实例适配范围仍由主 README 定义，这不是任意 Polarion 实例的配置向导。

```powershell
git clone https://github.com/suzike-dev/polarion-super-sidebar.git
cd polarion-super-sidebar
node scripts/setup-runtime.mjs
$node = '.\.runtime\node-v24.22.2-win-x64\node.exe'
$npmCli = Join-Path (Split-Path (Get-Command npm.cmd).Source) 'node_modules/npm/bin/npm-cli.js'
if (!(Test-Path -LiteralPath $npmCli)) { throw '请将 $npmCli 设置为已安装 npm 的实际 npm-cli.js 路径。' }
& $node $npmCli ci --ignore-scripts
& $node scripts/version.mjs check
powershell.exe -NoProfile -ExecutionPolicy Bypass -File scripts/check.ps1

# 新用户直接配置本工具凭据。命令会提示用户名和隐藏的密码输入。
powershell.exe -NoProfile -ExecutionPolicy Bypass -File scripts/configure-polarion-credentials.ps1
# 使用访问令牌时，改为：
# powershell.exe -NoProfile -ExecutionPolicy Bypass -File scripts/configure-polarion-credentials.ps1 -AuthMode access_token

./.runtime/node-v24.22.2-win-x64/node.exe scripts/diagnose-install.mjs --check-cli --strict
powershell.exe -NoProfile -ExecutionPolicy Bypass -File scripts/install-dev-host.ps1
```

默认凭据保存在 `%LOCALAPPDATA%\Nanju\PolarionSidebar\credentials.json`，不会修改已有 MCP 凭据。PowerShell 的执行策略参数仅用于当前脚本进程，不改变全局策略。诊断的文件存在检查和 CLI `--version` 成功不等于账号认证成功；可先执行下列不联网解密检查，再在获授权的实际工作项验证业务访问。自定义凭据路径时，必须给这个检查显式加上同一 `-CredentialPath`，因为它不读取 launcher 配置。

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File scripts/start-polarion-worker.ps1 -ValidateOnly
```

若 CLI 位于非标准目录，或已有自定义 DPAPI 文件，可在安装时显式指定；参数只进入本工具 `launcher.json`，不改变用户全局环境：

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File scripts/install-dev-host.ps1 -PrepareOnly -ClaudePath 'D:\Tools\Claude Code\claude.exe' -CredentialPath 'D:\Private\polarion-credentials.json'
./.runtime/node-v24.22.2-win-x64/node.exe scripts/diagnose-install.mjs --check-cli --strict
powershell.exe -NoProfile -ExecutionPolicy Bypass -File scripts/start-polarion-worker.ps1 -CredentialPath 'D:\Private\polarion-credentials.json' -ValidateOnly
powershell.exe -NoProfile -ExecutionPolicy Bypass -File scripts/install-dev-host.ps1
```

CLI 路径必须是实际 `.exe` 或 CLI `.js/.mjs/.cjs`，不能是 `.cmd/.ps1` shim。环境覆盖也可使用 `POLARION_SIDEBAR_CLAUDE`、`POLARION_SIDEBAR_CREDENTIALS`、`POLARION_SIDEBAR_DATA`，但已保存的 launcher 参数优先用于其子进程。自定义 DataDirectory 时，可以用 `configure-polarion-credentials.ps1 -CredentialPath '<自定义数据目录>\credentials.json'`，或通过安装参数选择凭据路径。

`-PrepareOnly` 只产生原生启动器及 manifest，供诊断和验收使用，不会注册浏览器。正常安装随后在扩展管理页加载 `apps/extension/.output/chrome-mv3`，检查诊断页版本。移动已安装目录后，需要从旧目录卸载当前注册，再在新目录注册；生成的绝对 manifest 路径不能随意搬走后继续使用。

更换电脑/Windows 用户应重新运行凭据配置，不能把本机 DPAPI 密文当作可移植登录凭据。替换已有凭据须显式 `-Replace`，脚本保留加密备份并报告备份路径；卸载 Host 保留用户草稿、会话与凭据。
