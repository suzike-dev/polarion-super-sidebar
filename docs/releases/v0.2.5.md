## 基线范围

本版本收录当前可运行的浏览器扩展、本地 Host、HTML/画板/协议核心、SOAP 适配器、锁定依赖清单、构建与安装脚本、规格和验证报告。此为首个 Git 提交基线，先前开发版本不补造提交历史。

README 收录三张真实隔离测试截图：编辑器与 AI 协作、工程表格、画板 AI 应用。图片仅展示已存在的界面与示例内容。

不收录 node_modules、独立 Node 二进制、构建目录、已加载扩展的复制品、.research 原始资料、会话/草稿数据库、凭据和临时日志。历史报告中的 .research 路径指向本机验证证据，私有仓库保留报告而不打包原始运行数据。

## 关键变化

- 原生编辑状态校验排除安全序列化差异，恢复明确保存流程。
- 原生 div 图文容器保留图片引用变化后的标题、段落、背景色。
- 保存后独立回读；服务端 HTML 成为后续编辑基线，未知结果先对账。
- 持续 Claude Code 会话、每轮动态上下文、命令/Skills/MCP 与权限模式。
- 富文本和画板中的人机协作；画板提案由用户审阅应用，源文件与预览保存到 Polarion。
- 新增版本一致性脚本、CI、CHANGELOG、PR 模板与版本管理约定。
- 修复全新 checkout 首次安装运行时前缺少 .research/s1 输出目录的问题。
- 锁文件下载源切换至 npm 官方仓库；confbox 版本记录校正为本地实际使用的 0.2.4，完整性散列与官方包一致，其他依赖版本不变。
