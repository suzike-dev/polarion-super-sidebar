## 当前采用的设计依据

Apple Human Interface Guidelines 为主规范，苹果式的信息层级、克制的材质和直接响应的交互适配 Windows 浏览器扩展。既有 Fluent / Carbon 资料作为历史研究，不再作为并列视觉方向。

- [Apple HIG 布局](https://developer.apple.com/design/human-interface-guidelines/layout)：用对齐、间距和分组建立关系，内容优先，尺寸变化时保持任务完整。
- [Apple HIG 字体](https://developer.apple.com/design/human-interface-guidelines/typography)：平台系统字体、清楚的字重层级和可缩放排版。
- [Apple HIG 材质](https://developer.apple.com/design/human-interface-guidelines/materials)：材质用于表达控件层级，正文阅读区域保持稳定、清晰。
- [Apple HIG 工具栏](https://developer.apple.com/design/human-interface-guidelines/toolbars)：操作靠近对象，常用操作直接可见，低频选项按需展开。

具体数值是本产品的初始设计决策，不宣称是 Apple 官方指定值。官方布局页面已检索核对，其余专题链接保留用于实施阶段逐项核对。

| 间距与形状 | 4px 基准，优先 8/12/16/24px；小控件圆角 6–8px、弹层 12px。靠分组和对齐组织内容，减少多层卡片与常驻状态横幅。 |
| 工具栏 | 常用编辑动作保持单层、按功能分组。表格、图片的专属操作随选择出现；较窄宽度下收纳低频动作，不把必需控件裁掉。完整能力仍可从菜单和键盘访问。 |
| 正文与表格 | 大表格使用独立水平滚动和可见滚动入口，不压缩字号凑宽度；编辑、预览与对照保持一致的内容可达性。图片与原文附件身份保持完整。 |
| AI 区域 | 回答占主要高度；默认紧凑输入框随内容增长并设上限。上下文为一行摘要、详细内容展开；上下文占用弧线与百分比放在输入区底栏。原生命令、附件、权限选择继续保留。 |
| 执行反馈 | 当前动作必须可理解，例如读取正文、更新表格、等待批准；重复工具调用折叠进记录。连接状态不冒充每轮重新连接，不展示虚假进度。 |
| 材质 | 轻微材质用于工具栏和菜单，正文、表格、AI 长文使用稳定底色。不得大面积叠加模糊。降低透明度偏好下使用不透明表面。 |
| 交互 | 按下立即反馈；拖动分隔线与指针同步并捕获指针。弹层从触发位置展开，Escape 关闭并恢复焦点。动画不阻塞点击，减少动态效果时取消位移。 |
| 保存 | 服务端保存动作与本地草稿状态明确区分。成功状态以真实写入和回读结果为准，失败提示就近提供恢复操作，不能靠样式隐藏问题。 |

以上约束适用于悬浮富文本、停靠侧栏、AI 协作面板、菜单和画板入口；不复制 macOS 窗口交通灯，不改变 Windows 快捷键惯例。

## 历史研究参考

- [Fluent 2 字体](https://fluent2.microsoft.design/typography)：中文界面配合 Windows 字体栈，正文 14–16 px、辅助信息 12 px，按语义建立层级；不以大量小字号挤压内容。
- [Fluent 2 布局](https://fluent2.microsoft.design/layout)：4 px 间距基准，关联操作就近分组，优先用间距和对齐建立关系。
- [Carbon 产品字体策略](https://www.carbondesignsystem.com/building-blocks/foundations/typography/style-strategies)：采用面向长时间工作的紧凑产品排版。
- [Carbon 数据表格](https://www.carbondesignsystem.com/building-blocks/core/components/data-table/guidelines)：给工程表格足够宽度，明确行列与批量操作，不把宽矩阵缩成无法阅读的小字。
- [Radix 键盘与焦点规范](https://www.radix-ui.com/primitives/docs/overview/accessibility)：工具条、弹层、菜单的键盘路径与焦点恢复必须完整。
- [Claudian 上下文仪表](https://github.com/YishenTu/claudian/blob/main/src/features/chat/composer/toolbar/ContextUsageMeter.ts)：紧凑仪表弧＋百分比，详细 token 数据按需展开。当前实现读取本地 SDK summary，不累计消息计费量。
