≡默认排队，逐条引导

发出去就排上，不打断当前思路

  • 运行中发送一律排队，指令逐条列在输入框上方：发两条放两条，发三条放三条。
  • 超过 3 条默认折叠为「N 条排队」，点击展开 / 收起。
  • 每条后带「引导」：点击立即优雅打断当前任务，该条插队优先执行，上下文保留。
  • 队列条内可取消排队、停止当前任务；底栏不再随运行状态增减控件。
真实环境实测长任务运行中连发 4 条 → 默认折叠；展开后对第 2 条点「引导」→ 当前轮标记「已打断」，执行顺序变为 1→2(引导)→其余按 FIFO，全程底栏排布不变。
